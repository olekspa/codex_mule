# Unofficial DLSS 5 / DLSS Neural Rendering — Confirmed Game Compatibility

**Last updated:** August 28, 2026  
**Confirmed games:** **51**

This is a community-tracked compatibility list for **unofficial / injected DLSS 5 / DLSS Neural Rendering** support, including RenoDX-style implementations and use of `nvngx_dlssnr.dll`.

## Confirmation standard

A game is counted as **confirmed** only when there is evidence of an actual playable in-game implementation, such as:

- direct screenshot/video/benchmark evidence;
- an installable working mod;
- multiple credible independent reports; or
- explicit first-hand confirmation supplied by a tester/user.

Requests, speculation, generic compatibility claims, and official/native support without demonstrated unofficial injection are **not** enough.
